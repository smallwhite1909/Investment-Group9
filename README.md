# Investment Group 9 · Lasso comparison

投资学第9组：A股截面选股，比较基本面打分、综合打分、Ridge、Lasso和浅层LightGBM。采用日频输入、未来20个交易日收益预测、每20个交易日调仓的等权Top100组合，数据覆盖2018-01-02至2026-04-29。

## 策略与结果

每日收盘更新分数，在连续交易日历上每20日更新目标，下一开盘交易；受限订单可逐日重试。五方法和主基准使用相同的历史完整输入股票池。主基准为该池等权组合，采用相同调仓频率、交易限制及匹配费用；CSI500价格指数仅作辅助参考。

采用年度模型和已固定的逐年因子、方向及参数，见[config.json](config.json)。先按行业和对数市值处理分数，再作因果EMA：基本面、Ridge和Lasso为20，综合和LightGBM为40。Ridge的alpha为10000；LightGBM深度3、7叶子、56轮。原四方法直接重训固定方案；Lasso按固定的年度历史内部验证规则选正则化强度。

| 方法 | 2021–2025费后收益 | 2026截至4月29日费后收益 | 2026累计每日费后超额 |
| --- | ---: | ---: | ---: |
| 基本面 | 139.90% | 3.53% | -4.25个百分点 |
| 综合打分 | 145.46% | 9.73% | +1.33个百分点 |
| Ridge | 195.66% | 8.80% | +0.56个百分点 |
| Lasso | 128.45% | 7.52% | -0.65个百分点 |
| LightGBM | 178.42% | 5.56% | -2.40个百分点 |
| 同池等权基准 | 76.60% | 8.18% | +0.00个百分点 |

Lasso在本次两个比较区间仍低于Ridge。2021年采用可排序候选中的历史验证最优模型，保留1个因子；2022/2024年保留7个，2023/2025年保留8个，2026年保留6个。2023/2025最优强度落在极弱惩罚边界，接近无正则线性回归。

Lasso与Ridge共用八个截面秩输入、年度成熟训练标签、EMA20及Top100规则。内部训练标签退出日早于前一日历年验证开始，验证标签退出日早于预测年；比较15个训练alpha_max比例，以逐日等权验证MSE选参，按完整成熟历史重算alpha_max后重训。正式候选须有非零系数，且在每个验证日产生非恒定截面排序；最终重训的每日预测也须能排序。全零模型的验证损失保留为诊断，不进入Top100模型选择；未添加现金择时规则。2026属于已查看历史的时间外复评。

首个信号为2018-07-11，首次成交为2018-07-12，与原比较方法相同。此前为共同预热期。旧版将全零Lasso接成现金策略，导致2018–2021长期横线；该不可比方案已纠正，原实验记录仅作内部诊断保留。

佣金单边3bp、滑点5bp；卖出印花税在2023-08-28前为10bp，此后5bp。绝对收益复利累计；超额曲线累加每日策略收益减同费用基准收益，不等于两个累计收益直接相减。完整历史包含2018–2020年的拟合回放；2021年起逐年训练只使用预测开始前已成熟的标签。

## 运行

使用Python 3.9、Conda环境`ashare`，从仓库根目录执行：

```bash
conda activate ashare
python -m pip install -r requirements.txt
python code/run.py \
  --data-dir /path/to/prepared-market-arrays \
  --features /path/to/prepared-factors.npy \
  --actions /path/to/corporate-actions.csv \
  --output /data/share/XingyuLargeFiles/Investment-Group9
```

`--data-dir`提供准备好的市场数组、历史基础股票池和收益标签；`--features`为16列因子面板；`--actions`为带来源的公司事件表。具体文件、轴顺序、字段、公式见[data_dictionary.md](data_dictionary.md)。完整运行从这些输入重新训练，不依赖旧项目的研究工件。仅克隆仓库不会取得数据；程序不包含从供应商数据库下载或重建原始财报快照的流程。

默认`--stage all`会训练全部五方法、重建回测并生成报告和展示。已有原四方法完整输出时，加`--stage lasso`只训练Lasso、核对基准重放并加入Lasso账本，然后更新报告和展示；不会重训原四方法。已有本管线的包含Lasso的`models/`、`results/`和`raw_baseline/`输出后，在同一命令中加`--stage report`可只重算诊断和重建文档；仍需原外部数据，用于信号诊断及实际持仓核验。

输出目录应位于仓库及home目录之外。重训分数、连续账本及对照分别位于`models/`、`results/`和`raw_baseline/`；Lasso年度参数、非零系数和内部验证分别为`models/lasso_fit_windows.csv`、`lasso_coefficients.csv`和`lasso_validation.csv`；图表、数值表和生成核验记录位于`report_assets/`。三份正式文档更新到仓库根目录。PPT文字、数字和表格为原生对象，图表为单独插入的高清图片；PDF保留矢量图表，按相同元素布局生成，未经PowerPoint原生导出验证。

年度费用柱将逐日费用/开盘NAV的比例在年内相加，单位为百分点；它不是复利终值损耗或年度费率。2026年度结果均截至4月29日。

Rank IC和五分组是未来20日标签诊断，不是费后交易收益；2021–2025诊断只用截至2025年底已成熟的标签，2026诊断截止4月29日，最后可评估的信号为3月30日。实际持仓图来自净值账本重放后的收盘权重，已核对重放交易数值不变。日频双倍滑点仍是日频对照。
